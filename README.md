# Finance Coach

Persönliches Kapitalfluss-Dashboard (Global Smart Money · ETFs & Aktien), jeden Montag um 06:37 Uhr (Berlin) aktualisiert.

**Webseite:** https://janitaberlin.github.io/financecoach/

## Regeln für jede Aktualisierung
- Jede Zahl mit Quelle, Datum und Vergleichswert (Durchschnitt und Vorjahr); keine erfundenen Zahlen.
- Kacheln oben immer in kurzen Stichpunkten; Hinweise eingeklappt.
- Jeder Lauf sucht selbstständig die großen Ereignisse der letzten Tage (Hacks, CEO-Wechsel, Kursstürze, Ausfälle, Unfälle, Börsengänge, Regulierung, Geopolitik, virale Finanz-Behauptungen), prüft sie mit Quellen und beantwortet „Wer steckt dahinter?“ (größte Eigentümer, Anteil von Vanguard/BlackRock/State Street, Staatsfonds, Betreiber) samt betroffener Aktien und ETFs.
- Keine persönlichen Positionsdaten auf dieser öffentlichen Seite.

Keine Anlageberatung. Alle Angaben ohne Gewähr.
